# 🌤️ Weather App

A simple and responsive Weather App built with **HTML, CSS, and JavaScript**, powered by the **OpenWeather API**.  
It allows users to search for any city and get real-time weather details such as temperature, humidity, wind speed, and conditions.

---

## 📖 About

This project demonstrates how to use APIs in JavaScript to fetch real-time data and display it dynamically in a user-friendly interface.  
It’s a great beginner-friendly project to practice **API integration**, **DOM manipulation**, and **responsive UI design**.

---

## ✨ Features

- 🔎 Search weather by city name  
- 🌡️ Displays temperature, weather condition, humidity, and wind speed  
- 🖼️ Dynamic weather icons  
- 📱 Responsive design for mobile and desktop  
- ⚡ Fast and lightweight  

---

## 🛠 Tech Stack

- **Frontend**: HTML, CSS, JavaScript  
- **API**: [OpenWeather API](https://openweathermap.org/api)
